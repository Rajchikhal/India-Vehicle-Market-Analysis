# 🚗 Vehicle Sales Analysis Dashboard (India)

A **Power BI dashboard project** analyzing vehicle models in India to uncover insights on **brand performance, pricing, fuel types, and market segmentation**.

---

## 📊 Overview

This dashboard provides an interactive view of the Indian automobile dataset (~15K records), helping users explore:

* Market distribution by brand
* Segment trends (SUV, Sedan, Hatchback, etc.)
* Fuel type preferences
* Pricing insights across brands

---

## 🎯 Objectives

* Identify top-performing vehicle brands
* Analyze pricing distribution and categories
* Understand fuel type adoption trends
* Enable interactive filtering for deeper insights

---

## 📁 Dataset

* File: `vehicle_models_india_15k.csv`
* Records: ~15,000
* Key Columns:

  * Brand, Model
  * Segment
  * Fuel Type
  * Price (Min, Max, Avg)
  * Launch Year

---

## 📌 Dashboard Features

### 🔢 Key Metrics (KPIs)

* Total Vehicles
* Average Price
* EV Count

### 📊 Visualizations

* Count of Models by Brand
* Count of Models by Segment
* Fuel Type Distribution
* Average Price by Brand
* Price Category Analysis

### 🎛️ Filters (Slicers)

* Brand
* Launch Year
* Segment
